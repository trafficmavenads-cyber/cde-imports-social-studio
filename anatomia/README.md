# Anatomia Quiz Lab

Site estático para treinar identificação de Anatomia com alfinetes. Categorias: Huesos, Músculos, Arterias, Venas, Nervios e MIX.

## Funcionalidades

- Quizzes ilimitados de múltipla escolha ou resposta aberta
- Imagem com alfinete em coordenadas percentuais para correta adaptação à tela
- Gabarito, revisão de erros, estatísticas e histórico no navegador
- Importação e exportação de questões em JSON com imagens e coordenadas
- Cadastro de novas imagens por clique na estrutura anatômica
- Sem servidor de dados, sem serviços pagos

## Observações

As imagens cadastradas no editor ficam apenas no dispositivo do estudante (IndexedDB). Exporte um JSON para fazer backup e compartilhar o banco de imagens. Para adicionar imagens permanentemente ao site público, os dados devem ser integrados ao projeto no GitHub.

O banco inicial contém exemplos de músculos extraídos da prancha de estudo compartilhada na conversa. Outras categorias serão incluídas quando forem fornecidas novas imagens validadas.
